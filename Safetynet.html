How to Use SafeNet (Step-by-Step)

  1. Download & Launch: Click the download button above, save the safetynet.exe file to your computer, and double-click to open it instantly (no installation required).
  2. Log Incident Details: Input the harasser's phone number or social handle, select the platform used (e.g., WhatsApp, SMS, Calls), and write a factual summary of what happened.
  3. Secure Evidence: Upload your screenshots or recordings. SafeNet automatically calculates a cryptographic SHA-256 hash for every file to guarantee tamper-proof courtroom integrity and locks it inside a local encrypted vault.
  4. Generate Official Dossier: Click generate to create a standardized legal text summary ready to hand over to cybercrime authorities.

Important: Handling Windows "SmartScreen" Security Warnings

Because SafeNet is a newly developed privacy utility created independently rather than by a commercial software corporation, Windows Defender may display a blue warning box when you first run it. This is normal for independent developer tools.

How to bypass the "Windows protected your PC" blue prompt safely:

  1. When the blue popup window appears, click on the small text link that says "More info".
  2. A button will appear at the bottom reading "Run anyway".
  3. Click "Run anyway" once, and the application will open normally forever after. Your data remains fully secure and offline.
