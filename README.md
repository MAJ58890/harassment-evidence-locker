# SafeNet: Secure Digital Evidence & Harassment Case Builder

SafeNet is a desktop application and digital forensics toolkit built with Python and CustomTkinter. It empowers individuals to collect, secure, and structure evidence of harassment or cybercrime entirely on their local machine, ensuring absolute privacy without relying on vulnerable cloud servers.

## Key Features
- **Local Encrypted Vault:** Utilizes Fernet symmetric encryption to lock uploaded chat logs, screenshots, and video recordings directly on the user's device.
- **Courtroom-Ready Integrity:** Automatically calculates SHA-256 cryptographic hashes for every evidence file to prove that no post-capture tampering has occurred.
- **Automated Legal Dossier:** Compiles incident narratives, harasser identifiers, and file hashes into a clean, professional text dossier formatted according to standard reporting requirements.
- **Built-In Action Guide:** Directs victims step-by-step toward official reporting channels—including direct links to the National Cyber Crime Investigation Agency (NCCIA) portal and 24/7 helplines—without risking public exposure or data leaks.

## Technology Stack
- **Python 3.x**
- **CustomTkinter** (Modern UI)
- **Cryptography** (Fernet encryption protocols)
- **Pillow** (Image metadata processing)
- **PyInstaller** (Standalone binary compilation)

## Disclaimer
SafeNet is developed strictly as a privacy and digital forensics utility to help victims preserve evidence and report crimes through official, legal state channels.
